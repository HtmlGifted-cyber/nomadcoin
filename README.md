# Nomad Coin website

Website for **Nomad Coin (NMD) 2.0, "The Wandering Coin"**: a fair-launch, CPU-mineable cryptocurrency for digital nomads, built on Bitcoin Core with HMQ1725 mining.

**Live: https://htmlgifted-cyber.github.io/nomadcoin/** · White paper: [whitepaper.html](https://htmlgifted-cyber.github.io/nomadcoin/whitepaper.html)

Plain HTML/CSS/JS, mobile-first, sharing its design with [htmlgifted-cyber.github.io](https://htmlgifted-cyber.github.io). Created by Jeremy A. Henry (BtcNomad).
