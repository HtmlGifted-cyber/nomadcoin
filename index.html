The Wandering Coin, rebuilt

Nomad Coin first launched on January 26, 2018, created by Jeremy A. Henry (BtcNomad). Its mission was simple: give people who live on the road a way to pay and get paid, with every payment visible on a public ledger.

The 2018 network, its exchanges and its original code are gone, so Nomad Coin 2.0 is a clean rebuild on a new chain. It keeps what defined the original: the HMQ1725 mining algorithm, a 210 million coin cap, and the nomad mission. It rebuilds everything else on current Bitcoin Core, so NMD speaks Bitcoin's language.

Trading NMD for Bitcoin

Because Nomad Coin is built on Bitcoin Core with SegWit and time-locked transactions from the start, it can reach Bitcoin in three steps as the network grows.

  1. Atomic swaps

    Two people trade NMD for BTC directly with matching time-locked contracts. Both payments complete or both refund, with no middleman.

  2. Decentralized exchanges

    Swap marketplaces that support Bitcoin Core-based coins can add an NMD/BTC market.

  3. Exchange listing

    With steady miners, always-on nodes, a public block explorer and real volume, NMD applies to exchanges that list community mining coins.

No one can promise a price or a listing. Value comes from people mining, holding and spending NMD.

FAQ

Is this the same coin as Nomad Coin 2018?

Same name, mission, algorithm and supply cap, on a brand-new chain. The 2018 network and its ledger no longer exist, so 1.0 coins do not carry over.

Can I buy NMD?

Not yet, and there is no presale or ICO. NMD will only come from mining when the main network launches.

What do I need to mine?

An ordinary Linux or Windows computer and an internet connection. The wallet download will include the miner.

When does the main network launch?

Once the 24/7 public node is running, so anyone can connect from anywhere. Follow this page for the date.
